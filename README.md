# QuickCart AI — Intelligent Shopping Cart & Item Prediction Engine

> High-dimensional vector embedding recommendation system for grocery e-commerce, computing real-time basket-level complementary product affinity using cosine similarity and semantic centroid clustering.

---

## Key Features

- **Vector Similarity & Basket Prediction**: Utilizes OpenAI `text-embedding-3-small` to map products into a 1536-dimensional semantic vector space. Cosine similarity calculations detect complementary items commonly purchased together.
- **Basket Centroid Aggregation**: Computes an aggregate vector centroid for the entire cart in real time to recommend items tailored to multi-item baskets (e.g., *Toor Dal* + *Basmati Rice* recommends *Desi Ghee* and *Jeera*).
- **Interactive Supermarket Interface**:
  - High-resolution product imagery and responsive layout.
  - Multi-category navigation: Dairy, Bread & Eggs, Atta, Rice & Dals, Tea & Beverages, Snacks, Masalas & Spices, and Instant Foods.
  - Authentic regional staples and national brands with Indian Rupee (INR) currency formatting.
  - Dynamic complementary item drawer ("Frequently Bought Together") triggered on item selection.
  - Slide-over shopping cart drawer with quantity management, threshold calculation, and basket completion recommendations.
  - Persistent theme configuration (Dark and Light modes).
- **Embedded Cache Optimization**: Local disk-persisted vector cache (`embeddings_cache.json`) eliminates redundant API requests and ensures sub-50ms server startup.

## Mathematical Foundation

### 1. Vector Cosine Similarity
Semantic affinity and complementary purchase likelihood between two items are quantified by computing the cosine of the angle between their high-dimensional vector embeddings:

$$\text{Cosine Similarity}(\mathbf{u}, \mathbf{v}) = \cos(\theta) = \frac{\mathbf{u} \cdot \mathbf{v}}{\|\mathbf{u}\|_2 \|\mathbf{v}\|_2} = \frac{\sum_{i=1}^{n} u_i v_i}{\sqrt{\sum_{i=1}^{n} u_i^2} \cdot \sqrt{\sum_{i=1}^{n} v_i^2}}$$

Where:
- $\mathbf{u}$ and $\mathbf{v}$ are $1536$-dimensional dense embedding vectors generated by OpenAI `text-embedding-3-small`.
- $\mathbf{u} \cdot \mathbf{v} = \sum_{i=1}^{n} u_i v_i$ denotes the inner (dot) product.
- $\|\mathbf{u}\|_2 = \sqrt{\sum_{i=1}^{n} u_i^2}$ represents the Euclidean ($L_2$) vector norm.
- **Range**: $[-1, 1]$. Values closer to $1.0$ indicate strong complementary relationship and purchase affinity.

Implementation reference (`src/item_service.py`):
```python
def cosine_similarity(self, a: List[float], b: List[float]) -> float:
    dot_product = sum(x * y for x, y in zip(a, b))
    norm_a = sum(x * x for x in a)
    norm_b = sum(y * y for y in b)
    if norm_a == 0 or norm_b == 0:
        return 0.0
    return dot_product / (math.sqrt(norm_a) * math.sqrt(norm_b))
```

### 2. Basket Centroid Vector (Multi-Item Recommendations)
When a user adds multiple products $I = \{i_1, i_2, \dots, i_k\}$ to their shopping cart, the system computes the aggregate **Basket Centroid Vector** $\mathbf{C}_{\text{basket}}$ representing the geometric center of all active items in the embedding space:

$$\mathbf{C}_{\text{basket}} = \frac{1}{k} \sum_{j=1}^{k} \mathbf{e}_j = \left[ \frac{1}{k}\sum_{j=1}^k e_{j,1}, \quad \frac{1}{k}\sum_{j=1}^k e_{j,2}, \quad \dots, \quad \frac{1}{k}\sum_{j=1}^k e_{j,1536} \right]$$

The recommendation engine then ranks all candidate catalog items $c \notin I$ using:

$$\text{Score}(c) = \text{Cosine Similarity}(\mathbf{C}_{\text{basket}}, \mathbf{e}_c)$$

> **Example**:
> - Adding **Maggi Noodles** + **Amul Butter** shifts the centroid toward quick snacks and dairy, recommending **Amul Cheese Slices**.
> - Adding **India Gate Basmati Rice** + **Tata Sampann Toor Dal** shifts the centroid toward traditional meal preparation, recommending **Amul Pure Desi Ghee** and **Catch Jeera**.

## OpenAI API Key Usage & Caching Architecture

### Why the OpenAI API Key is Required
The `OPENAI_API_KEY` environment variable is used by OpenAI's `text-embedding-3-small` model to convert unstructured product descriptions and natural language queries into 1536-dimensional numerical vectors:

1. **Semantic Vector Embeddings**:
   - Maps each product's metadata (Name, Category, Description, and Pairing context) into dense numerical coordinates in a shared semantic vector space.
   - Enables cosine similarity and basket centroid distance metrics to accurately detect complementary purchasing affinities.

2. **Real-Time Natural Language Semantic Search (`/api/search?q=...`)**:
   - Converts conversational or conceptual user queries (e.g., *"spicy snack for evening tea"*, *"midnight comfort food"*, or *"healthy breakfast grains"*) into query vectors on the fly, matching items by contextual intent rather than rigid keyword matching.

3. **Incremental Catalog Expansion**:
   - When new items are added to `items.json` that are not already present in the disk cache, the system automatically calls the OpenAI API to embed and persist them.

### Zero-Cost Caching Strategy
- **Pre-Warmed Disk Cache (`embeddings_cache.json`)**: All 1,060 grocery products are pre-computed and persisted to disk.
- **No Recurring API Calls for Browsing or Cart Recommendations**: Single-item pairings and multi-item basket centroid aggregations are calculated **100% locally** in Python memory in `<0.05ms`, incurring zero recurring API usage or latency.
- **Resilient Fallback**: If the server runs without an active `OPENAI_API_KEY`, the application boots successfully from disk cache to serve all catalog items and cart recommendations, with semantic search gracefully falling back to multi-token keyword matching.

## Installation and Execution

### Prerequisites
- Python 3.10+
- OpenAI API Key configured in `.env` (optional for local browsing, required for semantic search)

### Windows (PowerShell)

```powershell
# Activate virtual environment (if configured)
.\myenv\Scripts\activate

# Launch via application entrypoint:
python main.py
```

Alternatively, run Uvicorn directly:
```powershell
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```
